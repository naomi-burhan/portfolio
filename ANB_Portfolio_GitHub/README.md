# Anastasya Naomi Burhan — Portfolio

## Files
- `index.html` — portfolio website, based on the selected V7 version.
- `assets/` — images, CV PDF, and downloadable source files extracted from the original self-contained HTML.

## Run locally
Open `index.html` in a browser. Keep the `assets` folder beside it.

## Publish with GitHub Pages
1. Upload `index.html`, the `assets` folder, and this README to your repository.
2. In GitHub, open **Settings → Pages**.
3. Select the branch you want to publish and choose `/ (root)` as the folder.
4. Save and wait for GitHub Pages to publish the site.

External links (such as LinkedIn and Medium publications) remain external.
