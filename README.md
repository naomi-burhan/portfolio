# Anastasya Naomi Burhan — Portfolio

## Publish with GitHub Pages
1. Upload `index.html`, the `assets` folder, and this README to the root of your public repository.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then Save.
5. Wait for the Pages deployment to finish and open the URL shown in Settings → Pages.

Keep the `assets` folder beside `index.html`; it contains the downloadable CV and certificate images.
